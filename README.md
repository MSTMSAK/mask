# Mask — 智能投资平台

Mask 是一个面向个人投资者的智能分析平台，集成 AI 诊断、量化筛选、五维雷达与策略中心，帮助用户做出更理性的投资决策。

## 功能特性

- **五维雷达**：从基本面、技术面、资金面、情绪面、政策面五个维度综合评估个股
- **智能筛选器**：多条件组合筛选，快速发现优质标的
- **AI 诊断**：基于双引擎 AI（智谱 + Kimi）的实时诊断报告
- **策略中心**：量化策略回测与可视化
- **用户中心**：持仓跟踪与复盘管理

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Recharts

## 快速开始

```bash
npm install
npm run dev
```

## 项目结构

```
src/
  components/      # 组件
  components/ui/   # shadcn/ui 组件
  components/sections/  # 页面区块
  pages/          # 页面
  lib/            # 工具与数据
  hooks/          # 自定义 Hooks
  types/          # 类型定义
```
